Classification Models

After splitting the data, two classification models are selected to fit the training data. The code is in comapring_models.py The CV scores based on accurary are :-

Code 
df_model_comaprison = comparing_models()
df_model_comaprison
model meanCV stddevCV
0 Logistic Regression 0.974 0.019
1 Random Forrest 0.963 0.024

Both the models perform very well. Logistic Regression is slightly better and hence thats the final model.

To find the best set of hyper-parameters a GridSerchCV was run on the training dataset.

Code 
param_grid = {
